# Reto-Técnico

Cree un diseño de arquitectura para una aplicación nativa de nube
considerando los siguientes componentes:

---

- Frontend: Una aplicación web que los clientes utilizarán para
navegación.
- Backend: Servicios que se comunican con la base de datos y el
frontend.
- Base de datos: Un sistema de gestión de base de datos que almacene
información.
- Almacenamiento de objetos: Para gestionar imágenes y contenido
estático.

---
Diseño:
---
1. Seleccione un proveedor de servicios de nube (Aws, Azure o GCP) y
sustente su selección.
2. Diseñe una arquitectura de nube. Incluya diagramas que representen
la arquitectura y justifique sus decisiones de diseño (Utilice
 [diagrams](https://app.diagrams.net/)).
---
